# 02 — Format & Submission Specification

> Non-negotiable presentation rules. These are free marks — or free deductions.

## 1. Required format (verbatim from the brief)

| Setting | Required value |
|---|---|
| **Font** | Verdana, 11 point |
| **Spacing** | 1.5 spaced |
| **Margins** | Normal (2.5 cm, all sides) |
| **Referencing** | Harvard citation style |

**Verdana 11pt is unusual and highly visible.** A marker can tell at a glance if you used
the default Calibri/Aptos. Set it explicitly; do not rely on a template.

### Setting this in Word
1. `Ctrl+A` → Font: Verdana → Size: 11
2. Home → Paragraph → Line spacing: **1.5 lines** (not "Multiple 1.5", not "Double")
3. Layout → Margins → **Normal** (2.5 cm / 1 inch)
4. Apply to the **whole document, including the appendix and references**

### Trap
Changing the font *after* typing sometimes leaves table cells, headers, footers and
footnotes on the old font. Select each separately and re-apply.

## 2. Word count discipline

- **Limit: 300 words** for the answer.
- The **AI prompt appendix does not count** (stated explicitly in the brief).
- Assume **everything else does** count — body text, bullet points, table contents,
  figure labels — unless the handbook explicitly exempts them.
- Check whether the reference list counts. Most UK Harvard-style assessments exclude the
  reference list but include in-text citations. **Confirm this.**
- Use Word's `Review → Word Count` with "include textboxes, footnotes and endnotes"
  **unticked**, then recount with it ticked, and note both numbers.

At 300 words, every sentence must earn its place. The word budget in
`06-coursework-build/02-word-budget-and-structure.md` is the control document.

---

## 3. Structure of the submitted file

```
[Title / question restated — optional, counts toward 300, probably skip]

A. The Instrumental Rational Choice model            (~70 w)
B. My decision vs. the IRC counterfactual            (~80 w, table)
C. Theoretical explanation + literature              (~90 w)
D. Applying this in future                           (~60 w)

References                                           (Harvard, alphabetical)

Appendix 1: Generative AI prompts used                (excluded from word count)
```

## 4. Pre-submission checklist

### Content
- [ ] All **four** question components (A/B/C/D) are present and visibly signposted
- [ ] The IRC definition names its **components**, not just "rational = optimising"
- [ ] The counterfactual holds **my preferences constant** (see Trap 1 in `01-brief.md`)
- [ ] The theory used is one **taught on this module** — verified against lecture slides
- [ ] At least one **in-text Harvard citation**, correctly formatted
- [ ] Every in-text citation appears in the reference list, and vice versa
- [ ] The "future decisions" section is **specific and implementable**, not a platitude

### Format
- [ ] Verdana 11pt throughout (body, tables, headings, appendix, references)
- [ ] 1.5 line spacing
- [ ] 2.5 cm margins all round
- [ ] Harvard style, consistently applied (see `07-references/01-harvard-style-guide.md`)
- [ ] Word count recorded and within limit
- [ ] Appendix present if any generative AI was used
- [ ] File named per the module convention; correct file type (.docx / .pdf)

### Integrity
- [ ] **Every** generative AI tool used is logged in `00-assessment/03-ai-use-log.md`
      and declared in the appendix — see that file for why this matters
- [ ] Submitted to the right dropbox, before the deadline
