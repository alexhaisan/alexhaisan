## Which budget? Resolve this first

The lecture deck attaches **two different texts** to the two assessments:

| | Slide 6 → **FINAL essay** (2,000 w, 80%, 10 Dec) | Slide 7 → **INTERMEDIATE** (20%) |
|---|---|---|
| Define IRC + components | ✅ | ✅ (implied by "analyse using the model") |
| Describe a decision that deviates | ✅ | ✅ |
| Apply **each element** to your decision | — | ✅ **explicitly** |
| The IRC counterfactual with your preferences | ✅ | ✅ **explicitly** |
| Literature — a theory/experiment from the module | ✅ | ✗ not mentioned |
| How to decide better in future | ✅ | ✗ not mentioned |

**Budget A** assumes the 300 words answers **slide 7** (the analysis only).
**Budget B** assumes it answers the **full slide 6 question** compressed.

> If Moodle is ambiguous, **Budget A is the safer default** — it follows the wording
> explicitly attached to the intermediate assessment, and the task sentence ("applying the
> different elements of the model to the circumstances of your decision") is an instruction
> that needs real space to execute. You can add one citation inside Budget A cheaply as
> insurance; you cannot add a full four-part answer.

## Budget A — the IRC analysis (recommended default)

| Section | Words | Content |
|---|---|---|
| **A. The model** | **55–65** | IRC defined; the four components named (Action, Preferences, Expectations, Evidence); one line on *instrumental* |
| **B. The decision** | **35–45** | What I chose, when. Tight. |
| **C. Mapping the four components** | **100–115** | **The core.** One short block per component. Use a table. |
| **D. The counterfactual + the gap** | **70–80** | What an IRC agent with my preferences would do; what I did; which component failed |
| | **≈ 300** | |

**Why C gets the most words:** it is the only part the task sentence *explicitly* instructs
("applying the different elements of the model to the circumstances of your decision"), and
it's where four separate things have to be evidenced rather than one.

### Skeleton A

```
Instrumental Rational Choice (Elster, 1989) holds that an agent acts rationally
when their action is the best means to their own ends, given their beliefs —
reason serves ends it does not evaluate. Its components are Action, Preferences,
Expectations and Evidence.

Decision: [one sentence, with date].

| Component    | My decision                  | IRC requires                    |
|--------------|------------------------------|---------------------------------|
| Action       | [options I framed]           | all available choices listed    |
| Preferences  | [goals; the trade-off]       | — (cannot be irrational)        |
| Expectations | [what I believed]            | beliefs follow evidence, not wishes |
| Evidence     | [what I had/sought]          | optimal investment in search    |

An instrumentally rational agent with these preferences would have [X], because
[EU comparison]. I chose [Y]. The deviation is at [component]: [one precise
sentence]. In Elster's terms, requirement [(i)/(ii)/(iii)] failed.

References
Appendix 1: Generative AI prompts used
```

## Budget B — the full four-part question compressed

| Section | Component | Words |
|---|---|---|
| **A** | Define IRC + its four components | **65–70** |
| **B** | Decision + IRC counterfactual (table) | **85–95** |
| **C** | Theory/experiment + Harvard citation + **mechanism** | **85–95** |
| **D** | Applying it in future — architectural, not motivational | **50–60** |
| | | **≈ 300** |

Under Budget B the four-component mapping has to be compressed into the table in B, and you
must pick **one** theory from `../02-deviations-and-theories/` — confirmed as taught, which
after Week 1 means essentially IRC's own failure modes until more material arrives.

## Word-saving techniques that actually work

| Technique | Saving |
|---|---|
| **A table for the component mapping** | ~40 words vs prose — and it *displays* the mapping, which is what's being marked |
| Cut "In this essay I will…" / "It is important to note that…" | 10–20 |
| Cut hedges: "arguably", "to some extent", "quite", "rather" | 10–15 |
| Active voice: "I chose X" not "X was chosen by me" | 1–2 each |
| Name the model once, then "the model" / "it" | 5–10 |
| Bullets without leading verbs ("Preferences: reduce spending; retain access") | 15–20 |

## Words not to save on

- **The counterfactual sentence.** It's the hinge.
- **Which component failed, and why.** "I was irrational" is worth nothing; "my option set
  was unconsciously restricted — I framed a binary choice that was really four-way" is worth
  a lot.
- **The trade-off between conflicting preferences.** Slide 25 calls this *"an important
  element of the analysis"*. Most students will skip it.

## Drafting sequence

1. Complete `../01-core-theory/04-irc-worked-template.md` for the chosen decision
2. Draft with **no** word limit — get the analysis right first
3. Cut to 400 → 320 → 300. At the last stage cut **adjectives and connectives**, never content
4. Read aloud: is each of the four components still visibly mapped?
5. Format: **Verdana 11pt, 1.5 spacing, 2.5cm margins** (`../00-assessment/02-format-and-submission.md`)
6. References (Harvard) + AI appendix
7. Proofread
8. Final checklist

---

## Self-assessment before submitting

1. Are **all four components** (Action, Preferences, Expectations, Evidence) visibly mapped
   to my actual decision?
2. Does the counterfactual hold **my preferences constant**?
3. Have I named **which component** failed — not just asserted irrationality?
4. Have I avoided every item on the Deviation Test exclusion list (especially "it turned out
   badly" and "I was emotional")?
5. Could a marker find the counterfactual sentence **without hunting**?
6. Verdana 11, 1.5, 2.5cm, Harvard, ≤300 words, AI appendix present?
